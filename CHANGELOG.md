# Milestones

How ClassOf5 OS grew, in five stages (October 2026). Feature-by-feature release notes are kept privately.

| Stage | What it delivered |
|---|---|
| **1. Public website** | Marketing pages, pricing builder, FAQ, policies, enquiry forms |
| **2. Operations core** | Tutor scheduling across time zones, attendance from the classroom platform, admin tools |
| **3. Self-service enrolment** | Online sign-up and card billing, family portal, waiting lists and class capacity |
| **4. Learning & safety** | Lesson notes, homework, reports, recordings policy, safeguarding features, AI writing assistant with privacy masking |
| **5. Team & delivery** | Role-based staff access with audit trail, a staging environment, automated testing, CI/CD |

**Delivery:** 100+ releases in four weeks, each through a test environment before production.
